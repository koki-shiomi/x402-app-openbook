## Why

これまでの Arc Testnet は開発環境として扱い、今後の刻印・決済・第三者による検証を Arc メインネットへ統一する。技術デモとして実際の USDC とチェーンで成立する仕組みを示すため、開発中のデータを引き継がず、新しく収集を開始する。

## What Changes

- 刻印先を Arc メインネット（`eip155:5042`）へ変更する。2026-10-02 に配備済みの AnchorRegistry を使用する
- 決済は Circle の本番 facilitator とメインネットの Gateway Wallet を使用する。価格は実際の USDC で 0.10 USDC とする
- API・画面・共有の検証処理・公開文書が参照するチェーン定義をメインネットに統一する。接続先のチェーン ID が設定と異なる場合は刻印を送信しない
- **BREAKING**: 移行前の開発データを R2 から削除し、過去の対象日は一覧・取得の対象から外す。バックアップ・`retired/` への退避・旧データの復元は行わない
- 日次処理と手動再実行を停止した状態で旧データを整理し、メインネット版の公開後に収集を再開する。最初の収集は実行時点の前日（UTC 暦日）から始める
- 刻印用 EOA と決済の受取先は、運営者指定の `0xd77dd307A9E395fB2680011deeD994A27cf70d4b` を共用する。資金は必要に応じて追加し、年間運用分の確保を切替えの条件にはしない
- ソース公開検証は後続作業とし、メインネットへの切替えの必須条件から外す

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `hash-anchoring`: メインネットへの刻印とチェーン ID の照合、旧開発データを引き継がない再開条件を定める
- `paid-record-api`: メインネットで刻印されたデータを公開し、削除済みの旧対象日には支払いを求めず 404 を返すこと、メインネットでの決済・検証を定める
- `provider-credentials`: 刻印の署名鍵と受取先の共用を許し、資金を必要に応じて追加する扱いを定める

各能力の実装・テストは分けて進める。本番の切替えは、刻印・決済・検証の整合性を保つため一つの移行作業として行う。

## Impact

- API の刻印・決済設定、Web の接続・預入れ・検証、共有パッケージのチェーン定義
- `apps/api/src/schedule.ts` の空のストレージからの収集と埋め戻しの確認。既存の前日収集の仕様を維持する
- R2 の旧データ削除スクリプトと、日次処理・手動再実行を停止して切り替える手順
- シークレット `ARC_RPC_URL`・`ARC_ANCHOR_CONTRACT`・`X402_FACILITATOR_URL`・`X402_PAY_TO`
- README・`apps/web/public/openapi.json` などの公開文書（使い方はREADME、仕様は既存のOpenSpecへ集約）
- 刻印と決済には実費が発生する。長期運用の資金確保や資金補充の自動化は対象外
- 既存のテストネット上のトランザクションは残るが、アプリから参照する運用は終了する
