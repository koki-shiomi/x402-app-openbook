## MODIFIED Requirements

### Requirement: 取得可能な日付の一覧

システムは、取得可能な対象日の一覧を支払いなしで提供しなければならない（SHALL）。一覧には対象日とそのリビジョン番号のみを含め、金額を含めてはならない（MUST NOT）。

一覧の対象は、レコードが存在し、かつ最新リビジョンが刻印済みの日とする。取得できない日を一覧に含めてはならない（MUST NOT）。刻印済みかどうかは、レコードの最新リビジョンと刻印済みの最新リビジョンを突き合わせて判定しなければならない（SHALL）。刻印が 1 件でも存在することをもって刻印済みと見なしてはならない（MUST NOT）。

一覧が示すリビジョン番号は、その日を取得したときに返るリビジョン番号と一致しなければならない（SHALL）。

刻印済みかどうかの判定は、現在設定している刻印先のチェーンに対して行わなければならない（SHALL）。別のチェーンで刻印された日を一覧に含めてはならない（MUST NOT）。公開するすべての情報は、利用者が現在の設定で検証できなければならない。移行前のチェーンを指す刻印は、その条件を満たさない。

訂正リビジョンが追加されてから刻印されるまでの間、その日はレコードの最新リビジョンだけが未刻印で、それより前のリビジョンは刻印済みである。刻印の有無だけで判定すると、この状態の日を取得できると誤って示し、示すリビジョン番号も実際に返るものと食い違う。

金額を含めないのは、一覧が有料の対象である日次レコードの代替にならないようにするためである。一覧を無料にするのは、利用者が存在しない日や刻印待ちの日に支払うことを防ぎ、取得する前に対象を選べるようにするためである。

#### Scenario: 一覧の取得

- **WHEN** 支払いを伴わずに一覧を要求する
- **THEN** 取得可能な対象日とそのリビジョン番号が返り、金額は含まれない

#### Scenario: 未刻印の日の除外

- **WHEN** レコードは存在するが未刻印の日がある状態で一覧を要求する
- **THEN** その日は一覧に含まれない

#### Scenario: 訂正リビジョンが未刻印の日の除外

- **WHEN** ある日のレコードに訂正リビジョンが追加され、そのリビジョンがまだ刻印されていない状態で一覧を要求する
- **THEN** その日は一覧に含まれない。刻印済みの古いリビジョン番号で一覧に現れることはない

#### Scenario: 刻印後の再掲

- **WHEN** 訂正リビジョンが刻印された後に一覧を要求する
- **THEN** その日が一覧に現れ、リビジョン番号は訂正後のものである

#### Scenario: 一覧のリビジョン番号と取得結果の一致

- **WHEN** 一覧に現れた日を取得する
- **THEN** 返るレコードのリビジョン番号は、一覧が示していた番号と一致する

#### Scenario: 別のチェーンで刻印された日の除外

- **WHEN** 現在の設定と異なるチェーンで刻印された日がある状態で一覧を要求する
- **THEN** その日は一覧に含まれない
