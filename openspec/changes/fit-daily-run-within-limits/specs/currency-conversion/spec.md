## ADDED Requirements

### Requirement: 再収集での記録済みレートの再利用

過去日を再収集するとき、当該日の既存レコードが対象の通貨ペアのレートを記録している場合、システムはレート提供元へ問い合わせず、記録されているレートをそのまま適用しなければならない（SHALL）。適用したレートの値・通貨ペア・提供元・公表日は、記録されていたものをそのまま引き継がなければならない（SHALL）。

既存レコードが当該通貨ペアのレートを持たない場合（取得に失敗して `incomplete` に記録されている場合を含む）は、通常どおり提供元へ問い合わせなければならない（SHALL）。

適用するレートは対象日から決定的に定まるため、同じ対象日に対する問い合わせは常に同じ結果を返す。再収集のたびに問い合わせ直しても結果は変わらず、1 回の実行で使える問い合わせ回数を消費するだけである。記録済みの値を用いることで、実行時刻によって選択が変わらないという既存の要件がより確実に満たされる。

これは「レート取得失敗時の扱い」が禁じる流用とは異なる。禁じているのは、対象日のレートを取得できなかったときに別の時点のレートで代替することである。ここで再利用するのは、同じ対象日について過去に正しく取得し、レコードに公表日とともに記録されている当該日のレートである。

#### Scenario: 記録済みのレートがある日の再収集

- **WHEN** 対象の通貨ペアのレートを記録している日を再収集する
- **THEN** レート提供元への問い合わせは行われず、記録されていたレートと公表日がそのまま適用される

#### Scenario: レートを持たない日の再収集

- **WHEN** 取得に失敗して当該通貨ペアが `incomplete` に記録されている日を再収集する
- **THEN** レート提供元へ問い合わせが行われる

#### Scenario: 再利用によって訂正が生じない

- **WHEN** 値が変化していない日を再収集し、記録済みのレートを再利用する
- **THEN** レートの違いによる訂正リビジョンは追加されない
