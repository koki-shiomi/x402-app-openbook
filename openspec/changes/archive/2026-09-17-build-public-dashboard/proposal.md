## Why

⑤で日次レコードを x402 決済つきの有料 API として公開したが、利用するには 402 応答の復号・EIP-712 の署名・`PAYMENT-SIGNATURE` の組み立てを自前で書く必要がある。実際に支払いを通すまでに何が必要かが分かりにくく、取得できる内容も見えない。

この API で何が取れるのかを、ブラウザで実際に 1 日分を買って確かめられる場を用意する。あわせて、返ってきたバイト列をその場でチェーン上の刻印と照合し、第三者検証が机上の話でないことを示す。

## What Changes

- 取得可能な対象日の一覧を、支払いなしで表示する
- ブラウザのウォレットを接続し、選んだ 1 日分を 0.10 USDC で購入する
- 購入した日の収益・費用の内訳、欠測、適用した為替レートを表示する
- 取得したバイト列をブラウザ上で検証し、チェーン上の刻印との照合結果を示す
- 取得した内容を保存せず、画面を離れると消えることを明示する
- 支払いに必要な事前準備（Arc Testnet の追加、テストネット USDC、Circle Gateway への預け入れ）を画面上で案内する

本チェンジが提供するのは **API の内容を確かめるためのデモ**であり、日次データの主たる取得経路は API そのものである。

## Capabilities

### New Capabilities

- `public-dashboard`: 有料 API を唯一の取得元とするブラウザ向けの閲覧画面。一覧の表示、ウォレットによる支払い、1 日分の明細の表示、取得したバイト列のブラウザ上での検証を担う

### Modified Capabilities

なし。

## Impact

- 新しいパッケージ `apps/web`（ブラウザ向けの静的な資産）を pnpm ワークスペースへ追加する
- `apps/api/wrangler.jsonc` に静的な資産の配信を追加する。API と同一のオリジンで配ることで、有料 API に CORS の設定を加えずに済む
- `packages/shared` の検証関数と刻印の照会をブラウザで用いる。`anchor-verification` が定める「ブラウザと Workers の両方で動作する」要件を実際に満たす
- 新しいドメインは取得しない。`workers.dev` のまま配る
