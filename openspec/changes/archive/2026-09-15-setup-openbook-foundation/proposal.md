## Why

個人開発アプリ Sizet の収益と費用を公開する「Sizet OpenBook」を構築する。本チェンジはその第1段階として、日次の財務データを記録するための基盤を整備する。

公開する財務データは、後続チェンジで Arc テストネット上のコントラクトにハッシュを刻み、改ざんされていないことを第三者が検証できる状態にする。そのため「どのバイト列をハッシュ対象とするか」がデータモデルとストレージの設計を規定する。この決定を費用収集・収益収集より先に確定させなければ、収集処理を作り直すことになる。

本システム全体は次の6チェンジで構成し、本チェンジはその①にあたる。

| #   | チェンジ                                | 役割                                                          |
| --- | --------------------------------------- | ------------------------------------------------------------- |
| ①   | setup-openbook-foundation（本チェンジ） | 日次財務レコードの形式・保存規約・バッチ実行基盤              |
| ②   | collect-daily-cost                      | Claude API / Cloudflare / Resend / Supabase の費用を日次収集  |
| ③   | collect-daily-revenue                   | AdMobの収益を日次収集                                         |
| ④   | anchor-daily-hash-on-arc                | 月次クローズで確定した日次レコードのハッシュを Arc テストネットへ刻印・検証 |
| ⑤   | serve-x402-paid-api                     | x402 による USDC 決済つき有料 API の提供                      |
| ⑥   | build-public-dashboard                  | 支払いから可視化までのフロントエンド                          |

## What Changes

- **日次財務レコードのデータモデルを定義する**。1日分の収益・費用を1つのレコードとして表現する。レコードは確定状態を持たず、代わりに各エントリが取得方式（実測・使用量からの算出・日割り推定）と、提供元が後から値を改訂しうるかを保持する
- **欠測を明示する仕組みを定義する**。取得できなかった対象は 0 円として扱わず、種別・識別子・理由とともに記録する
- **正準 JSON 表現を定義する**。同じレコードからは常に同一のバイト列が生成されることを保証し、これをハッシュ対象かつ API 公開形式とする
- **保存先を Cloudflare R2 とし、保存規約を定める**。リレーショナル DB は用いない。キーは日付から決定的に導出し、保存済みオブジェクトは上書きせず、訂正はリビジョンを追加する形で行う
- **通貨は JPY を集計基準とする**。USD 建ての費用は日次の換算レートを取得してレコードに記録し、換算前の原通貨・原金額・適用レートを併記して再計算可能にする
- **日次バッチと月次クローズの実行基盤を用意する**。Cron Triggers による定期実行、当月中の再収集、翌月の月次クローズによる書き込みの締切、実行結果の記録、手動再実行、収集ソースが部分的に失敗した場合の扱いを定める
- **リポジトリ雛形とデプロイ経路を用意する**。TypeScript / Hono / Vitest の構成で、Cloudflare Workers へデプロイできる状態にする

本チェンジは基盤のみを対象とし、実際のプロバイダからの費用・収益取得は②③で行う。月次収支を表すレコードは作らず、日次レコードの集計として算出する。

## Capabilities

### New Capabilities

- `financial-record`: 日次財務レコードのデータモデル、取得方式と改訂可能性、欠測の記録、正準 JSON 表現、バリデーション規則
- `snapshot-storage`: 日次レコードの永続化規約（キー設計、不変性、訂正リビジョン、クローズ済み月への書き込み禁止、取得インタフェース）
- `daily-batch`: 日次バッチの定期実行、当月中の再収集、月次クローズ、実行記録、手動再実行、部分失敗時の挙動
- `currency-conversion`: JPY 基準へ換算するための為替レート取得と、レコードへの記録方法

### Modified Capabilities

なし（新規プロジェクトのため既存仕様は存在しない）

## Impact

- **新規リポジトリ**: `sizet-openbook` を Sizet 本体とは独立したリポジトリとして構築する。Sizet 本体（`sizet` リポジトリ）のコードは変更しない
- **インフラ**: Cloudflare Workers（Cron Triggers 付き）と R2 バケットを新規に用意する。いずれも現在の利用量では無料枠内に収まる見込み
- **外部依存**: 為替レート取得のため外部 API を1つ利用する。取得元は design.md で選定する
- **後続チェンジへの制約**: 本チェンジで定めた正準 JSON 表現は、④のハッシュ刻印と⑤の API レスポンス形式をそのまま規定する。確定後の変更はハッシュ値の互換性を壊すため、バージョン識別子をレコードに含める。また④の刻印対象は、月次クローズが完了した月に属する日次レコードの最終リビジョンとなる
- **公開範囲**: 本チェンジ時点では R2 の内容を外部公開しない。公開は⑤の有料 API 経由で行う
