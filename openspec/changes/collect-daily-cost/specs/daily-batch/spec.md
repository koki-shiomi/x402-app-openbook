## MODIFIED Requirements

### Requirement: 収集ソースの登録

システムは、収集ソースを登録し、日次実行時に一括して呼び出せなければならない（SHALL）。各収集ソースは、対象日を受け取り、費用エントリまたは収益エントリの配列を返すものとする。

登録された収集ソースが 0 件でも実行は成立しなければならない（SHALL）。これは、収集ソースを持たない状態でも基盤単体を検証・デプロイできるようにするためである。

各収集ソースは、対象日を遡って取得できる期間を宣言しなければならない（SHALL）。宣言の方法は、対象日と実行時刻から取得可否を判定できるものとする。遡及可能期間は提供元ごとに異なり、宣言のない収集ソースは常に取得可能とみなす。

#### Scenario: 収集ソースが登録されていない状態での実行

- **WHEN** 収集ソースが 1 件も登録されていない状態で日次実行を行う
- **THEN** 実行は成功し、費用・収益がいずれも空のレコードが生成される

#### Scenario: 複数の収集ソースの実行

- **WHEN** 複数の収集ソースが登録された状態で日次実行を行う
- **THEN** すべての収集ソースが呼び出され、返されたエントリが 1 件のレコードに統合される

#### Scenario: 遡及可能期間を宣言した収集ソース

- **WHEN** 遡及可能期間を宣言した収集ソースに対し、期間外の対象日で取得可否を問う
- **THEN** 取得できないと判定され、当該ソースは呼び出されない
